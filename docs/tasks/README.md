# Карточки контекста задач

Для отдельной задачи создайте здесь короткий Markdown-файл, например `projects-members.md`. Карточка помогает продолжить работу в новом чате. Её содержание не оценивается при автоматической приёмке.

```markdown
# Название задачи

## Цель

## Текущее состояние

## Принятые решения

## Ограничения

## Важные файлы

## Проверка

## Следующий шаг
```

В «Проверке» укажите команду и фактический результат, в «Следующем шаге» — ближайшее действие. Обновляйте карточку после принятого изменения, а не после каждого сообщения агента. Не переносите полную переписку, пароли, cookie и токены.

Перед продолжением попросите агента в `Ask` прочитать карточку через `@`, сверить её с кодом и назвать расхождения. Она помогает восстановить контекст, но тоже может устареть.
